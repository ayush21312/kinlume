## Automatic Wikimedia Commons photos — October 19, 2026

API: https://commons.wikimedia.org/w/api.php
Documentation: https://www.mediawiki.org/wiki/API:Imageinfo
The app uses a bounded filename search and retrieves coordinates, thumbnail URLs, and
extended license/author metadata. It requires meaningful name agreement and a geotag
within 0.4 miles. It rejects obvious maps, documents, portraits, logos, and mismatched
locations, and accepts only recognized CC BY, CC BY-SA, CC0, or public-domain metadata.
This conservative check is not human verification; incorrect matching remains possible.
Original files are not downloaded into the project by the runtime. Image source pages,
authors, and license links are displayed in the detail page. Metadata is cached for one day.
No API key is needed. Missing/failed/weak matches retain the fallback image; coverage is
not universal. This is separate from the manually researched local photo collection above.
