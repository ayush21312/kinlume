# Kinlume

The symbol is a simple, filled K with rounded ends, a warm orange interior, and a black outline. The header, opening screen, and standalone SVG files share the same shape.

- Warm mark: #c67c4e
- Dark wordmark: #292622
- Typeface: native Segoe UI/system, medium weight
- Keep the symbol proportional and leave clear space around it.
- Use the name on its own, without a tagline.

## Files

- public/brand/kinlume-mark.svg — transparent symbol
- public/brand/kinlume-wordmark.svg — symbol and name
- public/brand/kinlume-icon.svg — dark app icon and favicon
- src/components/BrandLogo.jsx — shared React version

Existing internal storage prefixes and session-cookie names are retained so saved resources and account sessions survive the rename.
